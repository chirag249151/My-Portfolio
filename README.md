🌐 Chirag Sharma Portfolio

A modern and responsive personal portfolio website built using HTML, TailwindCSS, and JavaScript.  
It highlights my skills, education, projects, and contact form** with smooth animations and a clean design.

---

🚀 Features
- 🎨 Responsive UI with TailwindCSS  
- ⚡ Smooth animations using AOS (Animate on Scroll)  
- 📂 Sections for About, Skills, Education, Reviews, Contact**  
- 📬 Working Contact Form with validation  
- 🌑 Beautiful **gradient backgrounds** with modern design  

---

🛠️ Tech Stack
- HTML5
- CSS3 (TailwindCSS) 
- JavaScript (Vanilla JS)  
- AOS Animation Library
